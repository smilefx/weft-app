Your data stays on your machine

Weft runs standalone on your computer. All your Messages, imports, todos and notes get saved in one file in your data folder. There is no Weft cloud and no Weft account.

The assistant uses an inference server on your machine. Without one, chats, search and the workspace work as usual. Matrix, IMAP and iCalendar keep your data readable.

Questions

Do I need a Matrix account?

Yes, Weft is a Matrix client. Any homeserver works, your organisation's or a public one, with password or single sign-on. You can add as many accounts as you have. Mail is optional.

What do I need for the AI features?

A local inference server with an OpenAI-compatible API, such as Ollama, and the models named in the settings. Weft shows which ones are installed. Without it, chats, search and the workspace work as usual.

Can I keep using other clients?

Yes. Weft signs in as one more device of your account, so everything stays in sync with your other clients, encryption keys included.

Windows says it protected my PC

Weft is not signed with a paid certificate yet, so SmartScreen warns on the first install. Choose More info, then Run anyway. Updates after that do not warn.

macOS will not open it

Drag Weft to Applications and open it. If macOS refuses, open System Settings → Privacy & Security and choose Open Anyway. If it says the app is damaged, run this once in Terminal: 

xattr -dr com.apple.quarantine /Applications/Weft.app
How do updates work?

Weft checks for updates in the background and asks you to restart when it is ready. Your chats stay where they are.

Where is my data stored?

In one file and a media folder inside your user data folder. Back it up like any other file. Remove an account and its data goes with it.

What about Linux?

A linux build is planned, but not yet available. A Docker image is also in the works, for running Weft on a local server and using it in a browser.
